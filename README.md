# Minecraft Yönetici Güç Paneli Eklentisi

Yönetici Güç Paneli, Paper Minecraft sunucuları için hazırlanmış bir admin paneli eklentisidir; GUI admin paneli, uçuş kontrolü, yürüyüş ve uçuş hızı ayarlama, spawn konumu kaydetme ve spawn noktasına ışınlanma özelliklerini sunar.

## Install

1. Paper 1.21.11
